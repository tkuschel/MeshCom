# Wi-Fi Enterprise

The ESP32 supports WEP

Implementation of WiFi network using RADIUS authentication (WPA2-Enterprise or WPA3-Enterprise/IEEE 802.1X).

WEP
:  Wired Equivalent Privacy (Kabelnetzwerk-äquivalente Privatsphäre), ältester Sicherheitsstandard zur Verschlüsselung von WLAN-Netzwerken aus 1997/1999. Verschlüsselung mit statischen Schlüssel RC4-Algorithmus (64- oder 128-Bit). - Gilt als überholt und unsicher.

WPA
:  Wi-Fi Protected Access, Nutzung von TKIP. Nachfolger von WEP im Jahr 2003. Unsicher, anfällig für Angriffe.

WPA2
:  Wi-Fi Protected Access, Nutzung von AES. Ausreichend sicher, anfällig für Brute-Force und Krack-Angriffe, falls nicht gepatcht.

WPA3
:  Wi-Fi Protected Access, aktueller Standard, sehr sicher.
